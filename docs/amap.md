# 高德地图接入

地点编辑使用官方高德地图 JavaScript API 2.0，提供名称/地址搜索、地图点击选点、新增时自动定位到附近、围栏半径预览。新增地点按 GCJ-02 保存；旧 WGS84 地点显示时转换，服务端仍根据手机实际返回的坐标系校验。

## 配置

在高德开放平台创建或选择本应用的 **Web 端（JS API）** Key，将以下两项存入服务器 `.env`（root 所有、600 权限），然后重启考勤服务。不要使用 Web 服务 Key 替代 JS API Key，不要把凭据提交到仓库。

```dotenv
AMAP_JS_KEY=你的网页地图Key
AMAP_SECURITY_JS_CODE=对应的安全密钥
```

配置高德域名白名单时按控制台支持的格式仅允许实际考勤入口；本地验收如需临时地址需明确登记，完成后移除。账号、服务许可与额度按高德控制台的实际要求处理，不使用其他项目或示例中的 Key。

两项都未配置时服务仍可启动，地点编辑明确显示“高德地图尚未接通”；只有一项或格式错误会阻止启动，避免部署半套配置。

## 安全与运行方式

`GET /api/maps/config` 仅组织管理员可调用，只返回浏览器所需的公开 Key。安全密钥不会写进前端或 `/api/state`。

客户端在加载官方脚本前设置 `serviceHost` 为当前源的 `/_AMapService`。服务器只转发列入白名单的地点搜索和地图样式 GET 请求，目标主机固定，覆写 Key/安全密钥，不转发客户端 Cookie/认证头；限制回调名称、请求长度、响应大小和时间。普通用户与考勤组管理员不能借用代理。

高德组件需要动态编译脚本，因此仅为已登录组织管理员的 HTML 页面启用 CSP `unsafe-eval`；未登录页面、普通用户、考勤组管理员及未配置地图时不启用。脚本来源仍限制为本站、飞书官方 SDK 和高德官方 API，不允许任意外部脚本或内联脚本。

手机飞书登录成功、应用页面打开后即开始准备飞书定位，不阻塞首页。结果仅在页面内存保留 60 秒供地图使用，不写入浏览器持久存储或服务器；实际打卡始终重新获取位置。地图打开时复用这次定位或正在进行的请求，“重新定位”主动刷新。

前端仅在打开地点编辑时加载高德脚本，保留高德原有地图标识。关闭面板会销毁地图，取消后到达的定位/搜索结果不再修改表单。正式模式定位使用飞书 JS API（浏览器 GPS 仅限本地演示），不把城市级 IP 定位作为打卡位置。

## 验收

- 用真实配置确认底图、名称搜索、选点和半径圆正常显示；验证地图加载/搜索失败可重试。
- 既有 WGS84 点显示和编辑后仍在同一物理地点；坐标字段隐藏，由地图自动处理。
- 新增地点自动获取飞书位置；被拒绝时仍可搜索。正在搜索、拖动、选点后到达的定位不能覆盖用户操作；编辑保留已保存中心。
- iPhone 飞书内验证授权/拒绝、正常定位、范围内外和重复提交。自动测试/桌面手机尺寸预览不能替代真机验收。
