# 角色与操作流程

保留现有管理工作台的布局与视觉样式，通过明确的先后依赖和下一步入口完成考勤配置，不要求用户理解接口或坐标转换实现。

## 组织管理员

首次从工作台进入且没有今天或之后的排班时，进入管理首页。配置顺序为：

1. 在高德地图搜索园区/楼栋，选定中心，确认半径并保存地点。
2. 使用已有默认考勤组或新建团队考勤组。
3. 从飞书组织选择成员，加入对应组；需要时设置考勤组管理员。
4. 选择成员、日期、工作时段和每段的地点；保存后排班立即对成员可见。
5. 本人或已排班成员在手机飞书试打卡，返回记录核对。出现记录只说明产生过打卡，不能自动证明范围边界和所有真机场景都通过。

首页根据实际数据显示进度，不保存人为完成标记。从引导打开的编辑在保存后返回首页，突出下一步；新建组和导入成员后保留当前组。直接通过导航进入的常规编辑仍停留原页面。已有默认组和本人身份可直接使用，无需重复创建。

缺地点或缺可管理成员时，排班页面给出相应入口；考勤组管理员缺地点时提示联系组织管理员，不进入无法保存的空表单。各组可直接进入成员或排班页，组范围随操作保留。

## 考勤组管理员

管理首页显示负责组的成员、排班、打卡记录进度。只管理已授权的组；使用组织管理员维护的地点，不出现地点、角色授权或系统接入入口。组范围同时由服务器校验。

## 普通用户

首次进入默认“今日打卡”，仅本人上下班按钮、工作时间和地点。没有今日排班时说明原因并提供“查看我的排班”。个人排班按日期列出，适合手机阅读；完成打卡后按钮显示已打卡时间，可到本人记录查看结果。

## 验证范围

前端与接口测试覆盖角色入口、配置依赖、所选组和下一步推导。真实用户操作还需确认搜索选点、保存后继续、手机定位及记录闭环。应用可用范围由飞书后台单独控制；添加考勤成员不会擅自扩大飞书发布范围。
